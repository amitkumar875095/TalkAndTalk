# Web Chatting App

A real-time web chatting application that allows users to chat with each other in various chat rooms. The app supports multiple users, live messaging, and real-time updates using Socket.io.

## Introduction

This project is a real-time web chatting application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) along with Socket.io for live communication. It allows users to join chat rooms, send and receive messages instantly, and have real-time updates without refreshing the page.

## Features

- **Real-time Messaging**: Messages are sent and received in real-time using Socket.io.
- **Multiple Chat Rooms**: Users can create or join different chat rooms.
- **User Authentication**: Users can sign up and log in to the application.
- **Live Status Updates**: See when users are typing or online.
- **Responsive Design**: Fully responsive UI built with React.

## Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **WebSocket**: Socket.io
- **Database**: MongoDB
- **Styling**: CSS / Material-UI (optional)
